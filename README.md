# BuildVista UAE website

This is the static website for the MIST 280 Fall 2026 BuildVista UAE project.

## Included pages

- Home
- Design Studio
- Service Packages
- Request a Quote
- Contractors
- Materials
- FAQ
- Contact
- Management and Employment
- Guarantee and Disputes
- Customer Feedback
- Privacy and Security

The site is built with plain HTML, CSS, and JavaScript. It has no paid theme, paid app, external font, external image, real payment gateway, or account system.

## Before final submission

1. BuildVista is a fictional course business. Keep the fictional phone and address clearly labeled as demonstration content; the group email is set to `202202311@uae.ae.ac` for the assignment contact.
2. Publish the folder with a free host such as GitHub Pages, a free website-builder plan, or another course-approved free static host. For GitHub Pages, create a public repository, upload the contents of this folder to the repository root, and keep `.github/workflows/pages.yml`. The included workflow deploys the site; if GitHub asks for a source, choose **GitHub Actions** in **Settings → Pages**. The public URL will look like `https://your-username.github.io/repository-name/`.
3. Open every page without login, test the navigation, and capture the nine required pages plus the home page on mobile for Appendix A.
4. Put the final public URL on the proposal cover page and in Appendix A.

All forms intentionally simulate confirmation only. They do not store submissions or process payments.
